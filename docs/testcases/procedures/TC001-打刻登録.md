# TC001: 打刻登録テスト

## テスト概要

**対象機能**: 出退勤打刻機能  
**対応パターン**: P001, P002, P005, P007  
**テスト目的**: 出勤・退勤打刻の基本動作とエラーハンドリングを確認する

## 前提条件

- テスト環境が正常に起動していること
- テストユーザーでログイン済みであること
- データベースが初期状態であること

---

## テストケース1: 通常の出勤打刻（P001）

### 因子
- 打刻状態: 未打刻（D02-1）
- 打刻時刻: 通常勤務時間（D04-1）
- ネットワーク: 社内LAN（E03-1）

### 観点
- 正常動作: 出勤打刻が正常に記録される
- データ整合性: データベースに正確に保存される

### 手順（Gherkin形式）

```gherkin
機能: 出勤打刻
  従業員として
  出勤時に打刻を行い
  出勤時刻を記録したい

  シナリオ: 通常の出勤打刻
    前提 従業員ID "EMP001" でログインしている
    かつ 当日の打刻記録が存在しない
    かつ 現在時刻が "2024-01-15 09:00:00" である
    
    もし 出勤打刻ボタンをクリックする
    
    ならば 打刻完了メッセージ "出勤打刻が完了しました" が表示される
    かつ 打刻時刻 "09:00:00" が画面に表示される
    かつ 打刻状態が "出勤済み" になる
    かつ データベースに以下の情報が記録される
      | フィールド | 値 |
      | employee_id | EMP001 |
      | clock_in_time | 2024-01-15 09:00:00 |
      | clock_out_time | NULL |
      | status | normal |
```

### 期待結果

- [ ] 打刻完了メッセージが表示される
- [ ] 画面に出勤時刻が表示される
- [ ] 打刻ボタンが「退勤」に変わる
- [ ] データベースに出勤時刻が記録される

## テストケース3: 重複出勤打刻エラー（P005）

### 因子
- 打刻状態: 出勤済み（D02-2）
- 打刻時刻: 通常勤務時間（D04-1）
- ネットワーク: 社内LAN（E03-1）

### 観点
- エラーハンドリング: 重複打刻を防止し、適切なエラーメッセージを表示

### 手順（Gherkin形式）

```gherkin
機能: 重複打刻の防止
  従業員として
  誤って出勤打刻を重複して行おうとした時
  エラーメッセージが表示されることを確認したい

  シナリオ: 出勤打刻済みの状態で再度出勤打刻を試みる
    前提 従業員ID "EMP001" でログインしている
    かつ 出勤打刻済み（打刻時刻: "09:00:00"）
    かつ 現在時刻が "2024-01-15 09:30:00" である
    
    もし 出勤打刻ボタンをクリックする
    
    ならば エラーメッセージ "既に出勤打刻済みです" が表示される
    かつ 打刻処理が実行されない
    かつ データベースの打刻記録が変更されない
    かつ 打刻状態が "出勤済み" のまま変わらない
```

### 期待結果

- [ ] エラーメッセージが表示される
- [ ] 打刻処理が実行されない
- [ ] データベースの内容が変更されない
- [ ] システムが正常な状態を維持する

## テストケース4: モバイルデバイスでの打刻（P007）

### 因子
- デバイス: スマートフォン（E01-2）
- ネットワーク: モバイル通信（E03-2）
- GPS情報: 正常取得（D05-1）

### 観点
- 正常動作: モバイルデバイスでの打刻が正常に動作
- ユーザビリティ: スマホUIが使いやすい

### 手順（Gherkin形式）

```gherkin
機能: モバイル出勤打刻
  従業員として
  スマートフォンから出勤打刻を行い
  GPS情報とともに出勤時刻を記録したい

  シナリオ: スマートフォンでの出勤打刻
    前提 従業員ID "EMP001" でスマートフォンからログインしている
    かつ 当日の打刻記録が存在しない
    かつ GPS機能が有効である
    かつ 現在位置が "緯度: 35.6812, 経度: 139.7671" である
    かつ 現在時刻が "2024-01-15 09:00:00" である
    
    もし 出勤打刻ボタンをタップする
    
    ならば GPS位置情報の取得確認ダイアログが表示される
    
    もし 「許可」をタップする
    
    ならば 打刻完了メッセージ "出勤打刻が完了しました" が表示される
    かつ 打刻時刻 "09:00:00" が表示される
    かつ 打刻場所 "東京オフィス" が表示される
    かつ データベースに以下の情報が記録される
      | フィールド | 値 |
      | employee_id | EMP001 |
      | clock_in_time | 2024-01-15 09:00:00 |
      | location | {"lat": 35.6812, "lng": 139.7671} |
      | status | normal |
```

### 期待結果

- [ ] スマートフォンで正常に打刻できる
- [ ] GPS情報が正確に取得・記録される
- [ ] モバイルUIが適切に表示される
- [ ] 打刻場所が判定・表示される
