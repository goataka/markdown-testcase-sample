# 因子分析

このドキュメントでは、打刻機能のテストにおける影響範囲を特定し、設定、データ、環境などの因子を整理します。

## 影響範囲の特定

PR #10の変更点から以下の影響範囲を特定：

### 1. データベース層
- 新規テーブル: `attendance`, `attendance_corrections`
- データ永続化処理
- トランザクション管理

### 2. API層
- 新規エンドポイント4つ
- リクエスト/レスポンス処理
- バリデーション

### 3. フロントエンド層
- 新規コンポーネント2つ
- ユーザー操作
- 画面表示

### 4. 通知システム
- 各種通知配信
- アラート機能

## 因子の特定

テスト結果に影響を与える因子を「設定」「データ」「環境」に分類：

### 因子カテゴリ1: 設定（システム設定）

| 因子ID | 因子名 | 説明 |
|--------|--------|------|
| S01 | 勤務形態 | フレックス、固定時間、シフト制 |
| S02 | GPS設定 | 必須、任意、無効 |
| S03 | 承認フロー | 1段階承認、2段階承認、自動承認 |
| S04 | 通知設定 | メール、アプリ通知、SMS |

### 因子カテゴリ2: データ（入力データ・状態）

| 因子ID | 因子名 | 説明 |
|--------|--------|------|
| D01 | 従業員ステータス | 正社員、契約社員、アルバイト |
| D02 | 打刻状態 | 未打刻、出勤済み、退勤済み |
| D03 | 前日の打刻状態 | 正常終了、退勤打刻なし、修正申請中 |
| D04 | 打刻時刻 | 通常勤務時間内、早出、残業、深夜 |
| D05 | GPS情報 | 正常取得、取得失敗、オフィス外 |

### 因子カテゴリ3: 環境（実行環境）

| 因子ID | 因子名 | 説明 |
|--------|--------|------|
| E01 | デバイス | PC、スマートフォン、タブレット、専用端末 |
| E02 | ブラウザ | Chrome、Safari、Firefox、Edge |
| E03 | ネットワーク | 社内LAN、モバイル通信、オフライン |
| E04 | データベース | 空データ、通常データ、大量データ |
| E05 | 時刻 | 平日、週末、祝日、月初、月末 |

## 因子の水準整理

各因子を水準として整理：

### S01: 勤務形態

| 水準 | 内容 | 備考 |
|------|------|------|
| S01-1 | フレックス | 出勤時刻が変動 |
| S01-2 | 固定時間 | 9:00-18:00などの固定 |
| S01-3 | シフト制 | 曜日や期間で時間帯が異なる |

### D02: 打刻状態

| 水準 | 内容 | 備考 |
|------|------|------|
| D02-1 | 未打刻 | 当日まだ打刻なし |
| D02-2 | 出勤済み | 出勤打刻済み、退勤未 |
| D02-3 | 退勤済み | 出勤・退勤両方済み |

### D04: 打刻時刻

| 水準 | 内容 | 備考 |
|------|------|------|
| D04-1 | 通常勤務時間 | 定時内 |
| D04-2 | 早出 | 通常開始時刻より前 |
| D04-3 | 残業 | 通常終了時刻より後 |
| D04-4 | 深夜 | 22:00-5:00 |

### E01: デバイス

| 水準 | 内容 | 備考 |
|------|------|------|
| E01-1 | PC | デスクトップ、ノート |
| E01-2 | スマートフォン | iOS、Android |
| E01-3 | タブレット | iPad、Android tablet |
| E01-4 | 専用端末 | 打刻専用機 |

### E03: ネットワーク

| 水準 | 内容 | 備考 |
|------|------|------|
| E03-1 | 社内LAN | 高速・安定 |
| E03-2 | モバイル通信 | 速度制限の可能性 |
| E03-3 | オフライン | 通信不可 |

## 因子と観点の関係

因子がテストの観点に与える影響：

### 観点1: 正常動作

**影響する因子**:
- D02（打刻状態）: 出勤→退勤の順序
- D04（打刻時刻）: 時刻の妥当性
- E03（ネットワーク）: 通信可能性

### 観点2: データ整合性

**影響する因子**:
- D03（前日の打刻状態）: データの連続性
- D02（打刻状態）: 重複防止
- E04（データベース）: データ量の影響

### 観点3: ユーザビリティ

**影響する因子**:
- E01（デバイス）: UI/UX適合性
- E02（ブラウザ）: 互換性
- S02（GPS設定）: 入力の手間

### 観点4: エラーハンドリング

**影響する因子**:
- D05（GPS情報）: 取得失敗時の動作
- E03（ネットワーク）: 通信エラー時の動作
- D02（打刻状態）: 不正操作の防止

### 観点5: 承認フロー

**影響する因子**:
- S03（承認フロー）: 承認段階
- D01（従業員ステータス）: 承認権限
- S04（通知設定）: 通知方法
